# Практическая работа №1.

## Определение типа деятельности

| №   | Ситуация                                                      | Тип деятельности   	| Краткое обоснование                                                                               |
| --- | ------------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------- |
| 1   | Разработать мобильное приложение для доставки еды за 4 месяца | **Проект**         	| Уникальный результат (новое приложение), конкретная цель и заранее заданный срок — 4 месяца.      |
| 2   | Ежедневно исправлять ошибки на существующем сайте             | Текущая деятельность 	| Повторяется ежедневно, не имеет даты завершения и уникального результата.                         |
| 3   | Создать новую базу данных для учёта студентов                 | **Проект**         	| Разовая работа с уникальным результатом (новая БД), которую нельзя выполнять «по кругу».          |
| 4   | Еженедельно создавать резервные копии базы данных             | Текущая деятельность 	| Регламентная операция по расписанию, результат каждый раз один и тот же.                          |
| 5   | Разработать систему электронного расписания для колледжа      | **Проект**        	| Уникальная система с конкретным назначением, работа заканчивается после сдачи продукта.           |
| 6   | Постоянно отвечать на обращения пользователей                 | Текущая деятельность 	| Непрерывный процесс поддержки, без срока окончания и без уникального продукта.                    |
| 7   | Перенести существующий сайт на новый сервер                   | **Проект** (мини)  	| Разовое мероприятие с чётким конечным результатом (сайт работает на новом сервере); не повторяется регулярно, хотя по масштабу близко к текущим задачам администрирования. |
| 8   | Ежедневно проверять работоспособность сервера                 | Текущая деятельность 	| Ежедневный мониторинг: повторяющаяся операция, заранее установленного завершения нет.             |

**Итог:** 
ситуации **1, 3, 5, 7** — проекты; 
ситуации **2, 4, 6, 8** — текущая деятельность.

## Обоснование (для ситуаций, определённых как проекты)

| №   | Цель                                                         		| Результат                                                                                 				| Ограничение по времени                	| Возможные участники                                                        			|
| --- | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1   | Автоматизировать приём и доставку заказов еды                		| Мобильное приложение для клиентов и сотрудников доставки: оформление заказа, оплата, отслеживание статуса 		| **Да — 4 месяца** (жёсткий срок)      	| Заказчик, руководитель проекта, аналитик, дизайнер, 1–2 разработчика, тестировщик 		|
| 3   | Заменить ручной/табличный учёт студентов единой базой данных   		| Спроектированная и заполненная БД студентов: структура таблиц, справочники, связь с оценками и группами 		| **Да, условно** — 1–2 месяца          	| Заказчик (учебная часть), аналитик, разработчик БД, тестировщик            			|
| 5   | Сделать актуальное расписание доступным без пересылки сообщений в чатах | Веб-система электронного расписания: просмотр занятий по группе, преподавателю и аудитории, отображение изменений 	| **Да, условно** — 3 месяца            	| Заказчик (администрация колледжа), руководитель проекта, аналитик, разработчик, тестировщик 	|
| 7   | Перенести сайт на новый сервер без потери данных и простоя     		| Сайт, развёрнутый на новом сервере, с перенесёнными файлами и БД, проверенной работоспособностью 			| **Да, короткое** — 1–3 дня (окно переноса) 	| Заказчик/владелец сайта, системный администратор, разработчик (проверка после переноса) 	|
